# ADR — Architecture Decision Records

되돌리기 어려운 선택, 기획서와 다른 결정, 대안이 둘 이상이었던 기술 선택을 한 결정당 한 파일로 남긴다. 형식은 Michael Nygard 스타일(Context → Decision → Consequences)이다.

- 파일 이름: `ADR-NNN-짧은-제목.md` (번호 세 자리, 제목은 kebab-case 영어 또는 한글)
- 상태: `Proposed` → `Accepted` → (`Deprecated` | `Superseded by ADR-NNN`)
- 한 번 Accepted 된 ADR은 고치지 않는다. 바뀌면 새 ADR을 쓰고 옛 것을 Superseded 로 표시한다.
- 템플릿: `ADR-000-template.md`
