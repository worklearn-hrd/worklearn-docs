# 워크런 디자인 브리프

학습자 7화면, 운영자 4화면, 테넌트 관리자 2화면, 플랫폼 운영자 3화면으로 총 16개 화면이다. 각 화면이 기획서 마일스톤의 몇 단계에서 구현되는지는 표의 '단계' 열에 있다. 1차 MVP(1–4단계, 공개 배포 게이트)는 학습자 7개 + 운영자 3개(대시보드 최소형·콘텐츠 관리·과정 편집) = 10개 화면이며, 테넌트 관리자·플랫폼 운영자 화면과 캠페인·AI 기능은 2차(5–6단계)다. 기술 내용은 뺐으므로 이 탭만 디자인 도구에 넘기면 된다.

## 제품 한 줄

워크런(WorkLearn)은 기업 임직원용 학습 플랫폼이다. 학습자는 직무에 맞는 과정을 수강하고 수료증을 받으며, HRD 운영자는 법정 필수교육 캠페인을 만들고 이수율을 관리한다. 회사(테넌트)마다 독립된 공간을 갖는다.

## 사용자

| 역할 | 누구 | 주로 하는 일 | 주 기기 |
| --- | --- | --- | --- |
| 학습자 | 임직원 전체 | 홈에서 넛지·추천을 보고 콘텐츠 시청, 퀴즈, 내 수강 현황·수료증 확인 | 모바일 + PC 반반 |
| HRD 운영자 | 교육 담당자 | 캠페인 생성, 이수율 모니터링, 미이수자 관리, 콘텐츠 업로드 | PC |
| 테넌트 관리자 | IT·인사 담당 | 테넌트 설정, HR 명단 업로드, 배치 작업 이력 확인 | PC |
| 플랫폼 운영자 | 워크런 운영사 직원 (테넌트에 속하지 않음) | 고객사(테넌트) 생성·정지, 초기 관리자 초대, 사용량 확인, 전체 테넌트 상태·배치·큐 모니터링 | PC |

| L2 | 홈 | 학습자 | 넛징카드(학습 중단·마감 임박 — 미읽음 알림 최신 2장), 진행 중 과정 이어보기, 필수교육 마감 D-day, 추천 콘텐츠, 동료가 많이 본 콘텐츠, 헤더의 알림 종 아이콘(드롭다운 알림함) | 2 · 알림 종·학습 시간은 5 · 넛징카드·필수교육·추천·동료 섹션은 6 |
| L3 | 탐색 / 검색 | 학습자 | 자연어 검색창, 주제·유형(영상/문서/Shorts) 필터, 결과 카드(콘텐츠 단위, 클릭하면 소속 과정 상세로) | 1 키워드 검색 · 자연어 검색은 6 |

| L7 | 마이페이지 | 학습자 | 수강 현황(진행/완료/만료), 학습 시간, 직무 필수·권장 과정 체크리스트, 북마크 목록, 수료증 다운로드 | 2 · 학습 시간은 5 |

## 핵심 흐름

1. 학습자: 홈 넛징카드 → 플레이어(이어보기) → 완료 → 퀴즈 → 마이페이지 수료증
2. 학습자: 검색 → 과정 상세 → 수강 신청 → 플레이어
3. 운영자: 콘텐츠 업로드 → 처리 상태 확인 → AI 태그 검토 → 과정 편집 → 캠페인 생성 → 대시보드에서 이수율 확인

4) 플랫폼 운영자: 테넌트 생성 → 프로비저닝 완료 확인 → 초기 관리자 초대 → 고객사 관리자가 T1 설정·T2 HR 업로드로 이어감

## 시각 방향

- 톤: 차분하고 신뢰감 있는 기업용. 소비자 앱처럼 화려하지 않되, 넛징카드와 진도 요소에는 생기가 있어야 한다.
- 브랜드 색: 프라이머리 한 가지(짙은 블루 계열 권장), 성공·경고·위험 상태 색 세 가지. 테넌트 브랜딩이 덮어쓸 수 있도록 프라이머리 의존도는 낮게.
- 타이포: 한국어 본문 가독성 우선. 한글 산세리프(Pretendard 계열) + 숫자가 또렷한 영문.
- 넛징카드: 홈 최상단, 한 번에 1\~2장, 행동 버튼 하나("10분 남았어요 · 이어보기"). 알림이 아니라 제안처럼 보여야 한다.
- 진도·이수율: 숫자보다 바와 링을 우선. 마감 D-day는 색으로 긴급도 표시.
- 소셜 프루프: 과정 상세와 넛지에 작은 문장으로("같은 직무 동료 73%가 이수"). 압박이 아니라 참고 정보 톤.
- 모바일: 학습자 화면은 모바일 퍼스트. 플레이어는 세로 모드에서 영상 상단·커리큘럼 하단 시트.
- 다크 모드: 없다. 플레이어만 어두운 표면(디자인 시스템의 dark 토큰)이고 나머지는 라이트.
- 빈 상태: 배정된 과정이 없을 때, 검색 결과가 없을 때, 콘텐츠 처리 실패 시 안내 문구와 다음 행동 버튼.

## 데모 테넌트 특이사항

- 외부 방문자가 이메일로 가입해 바로 수강할 수 있어야 하므로, 로그인 화면에 "데모 체험" 안내와 샘플 계정 설명이 들어간다.
- 방문자는 업로드·캠페인 생성을 할 수 없다. 운영자 화면은 방문자에게 열지 않는다.
