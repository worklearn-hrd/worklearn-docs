# BottomTabBar
모바일 학습자 화면의 고정 하단 탭. 탭 4개 고정: 홈·탐색·내 학습·마이.

- `surface` 바탕, 상단 `border`, 패딩 `10px 8px 28px`(하단 28px = 홈 인디케이터 안전 영역, `tabbar-safe-bottom`). `position: fixed; bottom: 0`.
- 항목 64×44, 아이콘 `icon-22` 위 라벨 11px 600, 간격 `space-4`. 비활성 `ink-secondary`, 활성 `accent`(아이콘·라벨 모두). 활성 표시에 밑줄·점·배경을 더하지 않는다.
- 아이콘은 선 아이콘 그대로(활성이라고 채우지 않는다). 배지(알림 수)는 두지 않는다 — 넛지는 홈의 카드로 보여준다.
- 플레이어·퀴즈 화면에서는 탭바를 숨긴다(몰입). 본문 하단 패딩은 탭바 높이(82px)만큼.
- 구현자가 넘기는 것: `activeKey`. 항목 목록은 상수.
