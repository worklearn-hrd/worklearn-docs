# 트러블슈팅 기록

한 시간 이상 잡아먹은 문제, 동시성 이슈 1~6의 재현→측정→해결 과정, 성능 전후 수치를 한 건당 한 파일로 남긴다. 기획서 §15의 원칙: **측정 없는 개선은 없다.** 숫자가 없는 기록은 기록이 아니다.

- 파일 이름: `YYYY-MM-DD-짧은-제목.md`
- 템플릿: `TEMPLATE.md`
- 동시성 이슈는 단계별 태그(`issue1-step0` …)와 Grafana 캡처를 함께 남긴다. 캡처는 같은 폴더의 `images/`에.
